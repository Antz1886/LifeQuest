# Contributing to LifeQuest 🛡️

First off, thank you for considering contributing to **LifeQuest**! It’s people like you that make LifeQuest such a great tool for the community.

## 🚀 How Can I Contribute?

### Reporting Bugs
- Check the [GitHub Issues](https://github.com/Antz1886/LifeQuest/issues) to see if the bug has already been reported.
- If not, open a new issue. Include as much detail as possible, such as steps to reproduce, the expected behavior, and screenshots if applicable.

### Suggesting Enhancements
- Open a new issue with the tag "enhancement".
- Describe the feature you'd like to see and why it would be beneficial to the "OS for the Self" philosophy.

### Pull Requests
1. Fork the repo and create your branch from `master`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints.
5. Issue that pull request!

## 🎨 Coding Standards
- **Style**: We use Tailwind CSS for all styling.
- **Components**: Use functional components with TypeScript.
- **Icons**: Use `lucide-react` for all iconography.

## 🤝 Community
Stay respectful and supportive. We are all here to grow and build better tools for ourselves and others.
