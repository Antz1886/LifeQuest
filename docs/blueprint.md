# **App Name**: LifeQuest

## Core Features:

- Daily Mission Dashboard: Display daily quests with RPG-style categories (Mind, Strength, Code, Wisdom, Legacy) based on preset time blocks. Auto-reset daily.
- Weekly Map & Scheduler: Visualize weekly schedule with drag-and-drop, color-coded blocks (Work, Study, Family, Biz). Highlight 'Boss Battles' for big tasks.
- XP and Leveling System: Award XP for completed tasks, streaks for consistent habits, and a leveling system with motivational rewards and titles.
- Focus Mode: Incorporate a Pomodoro timer with themed visuals (cyber grid, zen dojo) to enhance focus and earn rare achievements for deep work.
- Progress Tracker / Quest Log: Display visual analytics of time spent in each category, achievement board, and mood/energy tracking for personal insights.
- Project Vault: Create a project management that stores business ideas and tracks tasks in a campaign-style format to add to your dashboard
- Zen Zone: Add a built-in sound player to help track meditation, visualize weekly calm streaks, and visualize stress levels. Tie streaks to business or focus rewards.

## Style Guidelines:

- Primary color: A vibrant purple (#A020F0) to convey creativity and high-performance energy.
- Background color: A dark grey (#222222) to maintain focus with less visual noise and to clearly present data.
- Accent color: A electric blue (#7DF9FF) to complement the violet and draw attention to key elements and actions.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-forward look. Body font: 'Inter' (sans-serif) for readability in dashboards.
- Use clean, futuristic icons, reminiscent of RPG elements for daily missions, weekly progress, and profile badges.
- Design a dashboard-style layout, balancing data visualization and gaming elements (like a quest map).
- Subtle animations upon task completion, level up, and achievement unlocked. The animations will reinforce game mechanics.
